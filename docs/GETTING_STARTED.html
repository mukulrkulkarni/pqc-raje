Quick Start: CLI task

Run commands from the repository root with Python 3.10 or newer. Use the repository environment; no external service is required.

python -m compileall -q electre3 app
python scripts/convert_matrix_csv.py examples/assets_priority/matrix_with_headers.csv out/assets_priority_cli.npy --has-header --id-col Asset
python -m electre3.cli out/assets_priority_cli.npy examples/assets_priority/criteria.json -y

Expected converted-NumPy ranking lines:

1. 1
2. 0
3. 2

Approved CSV input has shape (N,C+1): column zero is a source identifier and the remaining columns are normalized scores. The direct CSV CLI preserves source identifiers, so the committed sample ranks B > A > C. The converter validates then removes identifiers; its numeric NumPy output receives positional identifiers 0, 1, and 2. This result applies only to committed sample data. The raw net-flow ranking is Φ(a) = Σb S(a,b) − Σb S(b,a), highest first. Scores are normalized to [0,1]; exact ties have no documented stable order.

Read the module tutorials or consult the repository docs/tutorials/cli_quickstart.md for flags and input rules.

Local web task

Run one command from the repository root:

python scripts/dev_local.py

The launcher prints the companion website URL http://127.0.0.1:8000/ and app URL http://127.0.0.1:5000/app/. Press Ctrl+C once to stop both services. Use distinct ports when defaults conflict:

WEBSITE_PORT=8100 APP_PORT=5100 python scripts/dev_local.py

On Windows Command Prompt, use set WEBSITE_PORT=8100&& set APP_PORT=5100&& python scripts\dev_local.py.

Select criteria JSON or use the structured form. Provide the matrix, review the preview, confirm the input, and compute the ranking. The results page shows top alternatives and raw net-flow scores.

The app serves HTML without JavaScript. It uses semantic HTML math. Browser reflow, browser zoom, keyboard, offline, and screen-reader evidence remain unverified as documented.

Input checks and recovery

Each criterion needs a name, positive weight, q, p, v, and Boolean maximize. Thresholds satisfy 0 ≤ q ≤ p ≤ v; weights sum to 1. The shared CLI/web validator accepts at most eight criteria.

The validator rejects missing fields, non-finite or out-of-range matrix values, and header/criteria order mismatches. Correct the input or apply the approved CSV missing-value replacement during preview. Do not bypass validation.
