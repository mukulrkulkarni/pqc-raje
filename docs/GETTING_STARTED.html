Quick Start

Install the package:

pip install electre3

Run a ranking:

from electre3.config import CriterionConfig
from electre3.ranking import compute_ranking
import numpy as np

G = np.array([[80, 70], [75, 85], [90, 60]])
criteria = [
    CriterionConfig("Price", weight=0.6, q=5, p=10, v=20),
    CriterionConfig("Quality", weight=0.4, q=3, p=8, v=15),
]
ranking, acc = compute_ranking(G, criteria)
print("Best alternative:", ranking[0])

ELECTRE III Method

This implementation uses ELECTRE III credibility computation with net flow ranking (a simplified approach). Alternatives are compared pairwise using:

  • Concordance: How much criteria support "a outranks b"
  • Discordance: How strongly any criterion vetoes the assertion
  • Credibility: Combined outranking strength S(a,b)
  • Net Flow: Final score φ(a) = Σ S(a,b) - Σ S(b,a) (replaces traditional distillation)

Note: Traditional ELECTRE III uses ascending/descending distillation for partial preorders. This implementation uses net flow scoring for a complete ranking.

Threshold Parameters

ParameterSymbolMeaning
IndifferenceqDifferences ≤ q are negligible
PreferencepDifferences ≥ p show clear preference
VetovDifferences ≥ v override concordance

Constraint: Thresholds must satisfy 0 ≤ q ≤ p ≤ v for each criterion.
