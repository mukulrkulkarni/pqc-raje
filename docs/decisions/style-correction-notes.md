### Positive, negative, and edge inventory

- **Positive:** Every owned tutorial has MK-TII tokens, keyboard semantics, no-JS hash fallback, and generated navigation CSS.
- **Positive:** Every owned landing page has target tokens, an active navigation state, and a focus-visible treatment.
- **Positive:** Full owned HTML crawl validates local paths and fragments; generated tutorial assets resolve through `website/modules/assets`.
- **Positive:** Generated tutorial output equals its normalized authoritative source and rebuilds idempotently.
- **Negative:** Synthetic missing local target and missing fragment both report exact failures.
- **Negative:** The generator rejects missing `<body>` and incomplete existing primary navigation.
- **Negative:** Static math checks reject remote MathJax/KaTeX renderer references.
- **Edge:** A `bodyguard` tag does not count as `<body>`; an anchor-only fragment resolves against its own document.
