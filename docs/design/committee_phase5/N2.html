1I/O Summary

a, b are objects (not criteria); a → b is the directed claim being assessed. Full definitions in Notation below.

partial_concordance(diff, q, p) Input: diff: ndarray(B1,B2,C) already-oriented differences g(a)−g(b); q, p: ndarray(C) indifference / preference thresholds
Output: ndarray(B1,B2,C), each cj(a,b) in [0,1]
Precondition: 0 ≤ q ≤ p (checked upstream by validate_thresholds)
global_concordance(c_j, weights) Input: c_j: ndarray(B1,B2,C), weights: ndarray(C) nonnegative, sum 1
Output: ndarray(B1,B2) = C(a,b) = Σj wj · cj(a,b)
Note: does not validate or normalize weights itself
Rule per criterion j cj = 1 if diff ≥ −qj;  cj = 0 if diff ≤ −pj;  else (diff + pj) / (pj − qj), clipped to [0,1]
Orientation: lower-is-better criteria are negated by ranking.compute_ranking before this call; direct callers must pass oriented data.

2Notation

a and b are objects Both are things being ranked (IP addresses, items, projects). They are not criteria. A criterion is a property we measure on every object.
a → b is an assertion under assessment a → b reads “a is at least as good as b”. We are testing this claim, not stating it is already established. b → a is a different claim with its own numbers.
Counts (no symbol collisions)
  • N — number of objects in the whole dataset
  • C — number of criteria (a count only)
  • C(a,b) — global concordance of the pair (a value in [0,1]); never plain C
B1 and B2 are comparison groups One block compares a group of B1 row objects (playing a) against a group of B2 column objects (playing b). These are object groups chosen for computation, not groups of data fields.
Why diff has three axes (B1, B2, C) diff[i,j,k] = g(row i, crit k) − g(col j, crit k). Axis 1 picks the row object, axis 2 the column object, axis 3 the criterion. Every a,b pair gets one number per criterion.
Triple brackets [[[d1, d2, d3]]] = B1 = 1 (outer), B2 = 1 (middle), C = 3 (inner). Two objects {A, B} give two non-self directed comparisons: A→B uses g(A)−g(B), B→A uses g(B)−g(A); same magnitudes, flipped signs.
Range
cj, C(a,b) ∈ [0,1]
Boundaries
diff = −q ⇒ c = 1; diff = −p ⇒ c = 0 (when q < p)
q = p
outer branch wins: c = 1 at and above −q, else 0; step semantics preserved
Monotone
cj non-decreasing in diff
Scientific grounding & boundary notes

Role in ELECTRE III. Concordance measures how strongly the criteria support the assertion a → b. Discordance can later veto it; credibility combines both.

Boundary at q = p. The denominator guard only prevents unsafe division. The nested np.where branches select 1 or 0, so the step function is preserved (verified by verify_example.py).

Weights. C(a,b) stays in [0,1] only if partial values are finite in [0,1] and weights are nonnegative and sum to 1. Use normalize_weights upstream.

Worked example: 1 row object × 1 column object × 3 criteria illustrative inputsoutputs verified by verify_example.py

Objects A and B; criteria C = 3, all already oriented higher-is-better. Inputs are illustrative, not recommended defaults.

InputValue
g(A), g(B)[10, 5, 7], [8, 7, 6]
q, p, v[1,1,1], [3,3,3], [6,6,6]
w (sum 1)[0.5, 0.3, 0.2]

Direction A → B. diff = g(A) − g(B) = [[[2, −2, 1]]] (B1=1, B2=1, C=3).

Partial cj(A,B). crit 1: 2 ≥ −1 ⇒ 1. crit 2: −3 < −2 < −1 ⇒ (−2+3)/(3−1) = 0.5. crit 3: 1 ≥ −1 ⇒ 1. So [[[1.0, 0.5, 1.0]]].

Global. C(A,B) = 0.5·1 + 0.3·0.5 + 0.2·1 = 0.85.

Discordance. all diff ≥ −p = −3 ⇒ dj = [[[0, 0, 0]]]. No veto, no reduction: S(A,B) = 0.85.

Reverse B → A. diff = [[[−2, 2, −1]]]. c = [[[0.5, 1.0, 1.0]]] (crit 3 sits exactly at −q, so c = 1). C(B,A) = 0.25 + 0.3 + 0.2 = 0.75; d = 0; S(B,A) = 0.75.

Read-out. Same two objects, two different directed claims, two different values. Source: example_results.json.

24    # Interpolation
25    denom = p - q
26    denom = np.where(denom == 0, 1.0, denom)
27    c_interp = (diff + p) / denom
28
29    # Apply piecewise conditions
30    c = np.where(diff >= -q, 1.0, np.where(diff <= -p, 0.0, c_interp))
31    return np.clip(c, 0.0, 1.0)

Purpose

Three regions for each criterion: diff ≥ −q gives 1, diff ≤ −p gives 0, otherwise linear (diff + p)/(p − q). The outer np.where wins on ties.

Why

Vectorised: c_interp is computed for every element, then masked. The final clip guards floating-point drift.

Pitfalls

q = p: the guard sets denom = 1; the outer branch still yields the step function. Sign: diff is g(a)−g(b); reversing a,b flips every sign. See Notation.
