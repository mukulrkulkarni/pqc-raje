End-to-end composition

Credibility S(a,b) → net-flow φ(a) → ranking order (no distillation)

Composition flow (what calls what)

Goal: rank N alternatives without storing an N×N matrix, using ELECTRE III credibility and a net-flow aggregation.

Step 1 — Credibility block

Compute a B×B credibility submatrix S for rows rs.. and cols cs.. using concordance and discordance.

Step 2 — Accumulate flows

Update outflow φ⁺ and inflow φ⁻ incrementally. Storage is O(N) for accumulator.

Step 3 — Net flow

Compute raw φ = φ⁺ − φ⁻ for each alternative. This is not a probability and not transitive.

Step 4 — Ranking

Return indices sorted by descending raw net flow: np.argsort(-acc.net_flow()).

O(N) accumulator memory O(B²) working block memory Not ELECTRE III distillation

Key contracts (diagonal, validation, normalization)

Diagonal exclusion

Self-comparisons must not contribute to flows. Diagonal is cleared only for diagonal blocks (rs==cs).

# In the block loop
is_diagonal = (rs == cs)
S = compute_block(..., is_diagonal=is_diagonal)
# diagonal blocks: S(a,a)=0; off-diagonal blocks: local diagonal is NOT "self"
Validation boundary

Entry points validate shapes, finiteness, and threshold consistency. Lower-level routines do not revalidate mutated state.

# High-level: rejects invalid input early
compute_ranking(G, criteria, config)
# Low-level block: assumes valid arrays and shapes
compute_block(G_rows, G_cols, q, p, v, weights, is_diagonal)
Normalization terminology

acc.net_flow() is the ranking signal. acc.normalize() is min–max scaling for display only.

Ties

Equal net flows can occur. The returned order is deterministic, but tie-breaking is not a mathematical guarantee.

Executable checks (what the tests assert)

The end-to-end tests verify the composition, not just individual primitives:

Pipeline correctness

Blockwise accumulator matches an independently computed full S reference on a small matrix.

Diagonal behavior

Diagonal exclusion only happens for diagonal blocks; off-diagonal local diagonal entries are preserved.

Validation

Invalid G / invalid weights fail before any call to compute_block.

Ranking uses raw net flow

Sorting never depends on acc.normalize().
