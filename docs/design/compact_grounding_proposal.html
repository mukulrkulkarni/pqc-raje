Scientific Grounding

Definition Discordance d_j(a,b) measures opposition from criterion j to the assertion "a outranks b." Values typically fall in [0,1]: 0 indicates no opposition, 1 indicates strong opposition (veto).
Assumptions Performance scales oriented so higher values indicate better performance. Thresholds p and v are in the same units as criterion scales.

Threshold Calibration

  • Source: Thresholds (p, v) typically elicited from domain experts or data variability analysis.
  • Units: p and v in the same units as the criterion performance scale.
  • Ordering: Must satisfy p ≤ v; validated upstream in config module.
  • Sanity-check: Thresholds larger than data range may have no effect.

Sanity Checks

  • Range: Verify all d_j values fall in [0,1].
  • Spot-check: Manually verify d_j matches piecewise formula for a few pairs.
  • Sensitivity: Test small threshold perturbations.
  • Missing data: NaN/Inf handled upstream; this module assumes complete data.
Proposed: single grounding strip (one border, three columns)
