Background

Background

Definition: Discordance d_j(a,b) measures opposition from criterion j to “a outranks b.” Values in [0,1]: 0 = no opposition, 1 = strong opposition (veto).

Assumptions: Scales oriented higher-is-better (after transformation). Thresholds p, v in criterion units.

  • Source: Elicited from experts or data variability.
  • Units: Same as criterion scale.
  • Ordering: p ≤ v (validated upstream).
  • Check: Compare vs observed data range.
  • Range: Verify d_j in [0,1].
  • Spot-check: Verify formula behavior.
  • Sensitivity: Test threshold perturbations.
  • Missing data: NaN/Inf handled upstream.
