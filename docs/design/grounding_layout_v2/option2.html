Option 2 — Accordion columns (three independent <details>)

Pros
  • Granular: readers open only the section they need; others stay one line tall.
  • All three section names + a teaser are visible while collapsed — strong discoverability.
  • Collapsed cost is one ~32px bar across the full width.
  • Native elements: each summary is a tab stop, toggled with Enter/Space; no JS.
Cons
  • Opening one column makes row heights uneven (ragged bottom edge).
  • Three toggles = more interaction cost to see everything.
  • Teaser text is truncated with ellipsis; relies on expanding for full content.
Collapsed (default): one bar, three labelled toggles
Grounding d_j ∈ [0,1]; 1 = veto

Definition: Discordance d_j(a,b) measures opposition from criterion j to "a outranks b." Values in [0,1]: 0 = no opposition, 1 = veto.

Assumptions: Scales oriented so higher = better; thresholds p, v in the same units as criterion scales.

Calibration p ≤ v, same units as scale
  • Source: expert elicitation or data-variability analysis.
  • Units: same units as the criterion performance scale.
  • Ordering: p ≤ v; validated upstream in config module.
  • Sanity: thresholds beyond the data range have no effect.
Sanity checks range, spot-check, sensitivity
  • Range: all d_j values in [0,1].
  • Spot-check: verify piecewise formula on a few pairs.
  • Sensitivity: perturb thresholds slightly; inspect deltas.
  • Missing data: NaN/Inf must be handled upstream.
