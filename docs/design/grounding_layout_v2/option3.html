Option 3 — Always-on facts line + <details> footnote

Pros
  • Must-know invariants are always visible — zero interaction, no hidden critical info.
  • Collapsed cost ≈ 30px facts line + one text-link row; lightest visual weight (no second border box).
  • Progressive disclosure matches reading intent: skim facts, expand rationale only if curious.
  • Semantic <dl> for facts + native <details>; keyboard and SR friendly, no JS.
Cons
  • Requires editorial judgement to pick which facts are "always-on."
  • Footnote link is subtler than a bar — slightly lower discoverability of the long form.
  • Facts line wraps to two lines below ~700px.

Scientific Grounding

Definition: Discordance d_j(a,b) measures opposition from criterion j to "a outranks b." Values in [0,1]: 0 = no opposition, 1 = veto.

Assumptions: Scales oriented so higher = better; thresholds p, v in the same units as criterion scales.

Threshold Calibration

  • Source: expert elicitation or data-variability analysis.
  • Units: same units as the criterion performance scale.
  • Ordering: p ≤ v; validated upstream in config module.
  • Sanity: thresholds beyond the data range have no effect.

Sanity Checks

  • Range: all d_j values in [0,1].
  • Spot-check: verify piecewise formula on a few pairs.
  • Sensitivity: perturb thresholds slightly; inspect deltas.
  • Missing data: NaN/Inf must be handled upstream.
