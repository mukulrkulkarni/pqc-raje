Scientific grounding & calibration notes

Notation: Let a and b be alternative objects. The credibility matrix entry S(a,b) measures the credibility of “a outranks b”. In block computation, each block row corresponds to an alternative in the current row comparison group, and each block column corresponds to an alternative in the current column comparison group. Net-flow ranking uses φ⁺(a)=∑ᵦ S(a,b) and φ⁻(a)=∑ᵦ S(b,a) (diagonal excluded). Net flow is φ(a)=φ⁺(a)−φ⁻(a).

Block mapping: A block S_block corresponds to global indices (row_start+i, col_start+j). The accumulator updates outflow[row_start+i] by the row sum and inflow[col_start+j] by the column sum.

Why this is correct: Summing all blocks (with no overlap and no gaps) is equivalent to summing the full matrix, but you never store N×N. This equivalence assumes the same weights and thresholds are used for all blocks (i.e., block partitioning is only a performance strategy).

If tiling is correct: If tiling covers each off-diagonal pair exactly once (no overlap, no gaps), and you use the same weights for all blocks, then the accumulated outflow/inflow correspond to the full-matrix row/column sums. In that case, outflow.sum() equals inflow.sum() within floating-point tolerance because both equal the total mass ∑ᵢ∑ⱼ S(i,j) over the covered pairs.

Limit of this check: Even with incorrect tiling, outflow.sum() and inflow.sum() still match (each update() adds the same block total to both sums). Treat equality of sums as a numerical sanity check, not a coverage proof.

Normalization caveat: Min-max scaling preserves order (monotonic) but hides absolute gaps and is sensitive to outliers. This project ranks by raw net flow; normalize() is for optional presentation.

Purpose

Accumulate net-flow ingredients using only two length-N arrays, not an N×N matrix.

I/O

  • n_alternatives is N, the number of alternatives.
  • Creates outflow and inflow as float64 arrays.

Why

Net flow needs only row sums and column sums of the credibility matrix S. Computing S block-by-block lets you scale to large N without O(N²) storage.

Pitfalls

The class is intentionally small. It does not validate tiling coverage or index bounds; the caller owns those invariants.

Purpose

Store the only state needed for net flow: two length-N vectors plus a counter.

I/O

  • outflow[i] accumulates ∑ⱼ S(i,j).
  • inflow[i] accumulates ∑ⱼ S(j,i).
  • blocks_done counts update() calls (loop sanity check).

Why

Even when each S(i,j) is in [0,1], you can add O(N) terms per alternative. Using float64 reduces rounding drift in large runs.

Pitfalls

n_alternatives must be non-negative. For N=0, NumPy constructs empty arrays but normalize() fails on min()/max(). For N=1, net_flow() is always zero when diagonal entries are excluded (there are no distinct pairs), but arbitrary update() calls can still change outflow/inflow numerically.

Purpose

Accumulate one computed block into the global flow vectors.

I/O

  • Input: S_block with shape (B1,B2) and global offsets row_start, col_start.
  • Effect: adds S_block.sum(axis=1) to the corresponding outflow slice and S_block.sum(axis=0) to the corresponding inflow slice.

Why

Because S_block[i,j] represents S[row_start+i, col_start+j], row sums contribute to outgoing dominance (φ⁺) and column sums contribute to incoming dominance (φ⁻).

Pitfalls

  • Preconditions (not enforced here): row_start, col_start are non-negative and row_start + B1 <= N, col_start + B2 <= N.
  • Tiling coverage: each off-diagonal pair appears exactly once across all blocks (no overlap, no gaps).
  • Swapping row_start and col_start can look plausible but is wrong; keep an asymmetric oracle test for this.

22    def net_flow(self) -> np.ndarray:
23        return self.outflow - self.inflow
24
25    def normalize(self) -> np.ndarray:
26        flow = self.net_flow()
27        min_val, max_val = flow.min(), flow.max()
28        if max_val == min_val:
29            return np.ones_like(flow) * 0.5
30        return (flow - min_val) / (max_val - min_val)

Purpose

Expose the scalar ranking signal: net flow φ = φ⁺ − φ⁻ for each alternative.

I/O

  • net_flow() returns outflow - inflow (can be negative).
  • normalize() returns a min-max scaled copy in [0,1] when non-degenerate.

Why

In this codebase, the final ranking is by raw net_flow() in descending order. Normalization is for optional presentation only.

Pitfalls

  • Min-max scaling is monotonic when max_val != min_val and values are finite, but it hides absolute scale and is sensitive to outliers.
  • If every net flow is equal, the denominator is zero; returning 0.5 is a deterministic convention.
R5 Tiling invariants: bounds, conservation, diagonal exclusion update()+net_flow() contracts

# The accumulator is deliberately minimal. It does not validate these:
#
# 1) Bounds:
#    0 <= row_start, col_start
#    row_start + B1 <= N
#    col_start + B2 <= N
#
# 2) Tiling (no overlap, no gaps):
#    Every off-diagonal pair (i,j), i!=j, appears in exactly one S_block.
#
# 3) Diagonal handling:
#    compute_block must zero the diagonal when row_start==col_start block.
#
# 4) Value sanity:
#    S_block should be finite; typical credibility values are in [0,1].

Purpose

Make the caller-owned contracts explicit: bounds, tiling coverage, diagonal handling, and numeric sanity checks.

I/O

No new API is introduced in this range. These notes define how to call update() safely and interpret the resulting flows.

Why

The accumulator is intentionally minimal to keep the hot path fast. The loop that drives block computation must enforce these contracts.

Pitfalls

  • Bounds: if slice length and sum length differ, NumPy raises a broadcasting error; if they match by accident, results corrupt silently.
  • Tiling: if you skip a block you undercount; if you repeat a block you double-count (no overlap, no gaps).
  • Diagonal: ensure diagonal entries are zeroed upstream for diagonal blocks.
  • Sum equality: outflow.sum() equals inflow.sum() even for incorrect tiling; do not treat it as coverage proof.

Usage example

example.pysnippet
from electre3.accumulator import NetFlowAccumulator
import numpy as np

acc = NetFlowAccumulator(3)

# S is a credibility matrix sample (diagonal already zeroed).
S = np.array([[0.0, 0.8, 0.6],
              [0.2, 0.0, 0.7],
              [0.4, 0.3, 0.0]])
acc.update(S, row_start=0, col_start=0)

print(f"Outflow: {acc.outflow}")
print(f"Inflow: {acc.inflow}")
print(f"Net flow: {acc.net_flow()}")
