Purpose

Specifies one criterion with thresholds and direction. Concordance/discordance modules use these parameters.

I/O

  • name — identifier for logging
  • weight — relative importance (normalized downstream)
  • q, p, v — indifference, preference, veto thresholds
  • maximize — True = higher is better

Why

Dataclass gives typed fields with automatic __init__. The maximize flag lets engine handle cost criteria without preprocessing.

Pitfalls

Setting q > p or p > v raises ValueError. Zero weight passes here but fails normalization.

Purpose

Enforces 0 ≤ q ≤ p ≤ v. Invalid orderings produce undefined preference relations.

I/O

Input: fields from init. Output: None or ValueError.

Why

Concordance computes (d-q)/(p-q). If p ≤ q, this causes division by zero. Validating at construction prevents NaN propagation.

Pitfalls

Equal thresholds (q == p) are valid — models binary preference. Tests verify each boundary.

Purpose

Controls execution: block size for memory partitioning, JIT toggle, random seed for tie-breaking.

I/O

  • block_size — alternatives per block, O(block_size²) memory
  • use_numba — JIT compilation (10-100x faster)
  • seed — enables reproducible tie-breaking (optional)

Why

N×N comparisons for N=100k needs 80GB. Block processing keeps memory at O(block_size²).

Pitfalls

Small block_size (e.g., 10) increases overhead. Without seed, tie-breaking order may vary between runs.

Purpose

Prevents zero/negative block sizes. ceil(N/0) is undefined; negative causes infinite loops.

I/O

Input: block_size. Output: None or ValueError.

Why

Block module uses range(0, N, block_size). Zero or negative never terminates.

Pitfalls

Type system rejects floats. Tests verify boundary: 0 raises, 1 passes.

R5 Weight Normalization L34–L38 pure

34def normalize_weights(criteria: list[CriterionConfig]):
35    total = sum(c.weight for c in criteria)
36    if total <= 0:
37        raise ValueError("total > 0")
38    return [c.weight / total for c in criteria]

Purpose

Transforms weights to sum to 1.0. Concordance requires Σwⱼ = 1.

I/O

Input: list[CriterionConfig]. Output: list[float] summing to 1.0.

Why

Users specify ratios (3:2:1) without manual division. Preserves relative importance.

Pitfalls

Empty list yields total=0 and raises. Mixed signs can sum to zero — also caught.
