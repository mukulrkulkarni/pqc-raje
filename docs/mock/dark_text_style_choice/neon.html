from dataclasses import dataclass

@dataclass(frozen=True)
class Thresholds:
    # indifference / preference / veto
    q: float = 0.05
    p: float = 0.2
    v: float = 0.6

    def validate(self):
        if not self.q <= self.p < self.v:
            raise ValueError("q ≤ p < v required")

Purpose

Holds the three ELECTRE discrimination thresholds as one immutable value object so every module reads the same numbers.

Inputs & outputs

  • In: q, p, v floats (defaulted)
  • Out: frozen Thresholds instance
  • Raises: ValueError on bad ordering

Why

Freezing prevents mid-run mutation; validation fails fast at construction instead of deep inside the outranking step.

Pitfalls

  • Equality of p and v is rejected by design.
  • Defaults assume criteria scaled to [0, 1].
