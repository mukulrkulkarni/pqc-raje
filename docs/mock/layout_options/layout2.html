Thresholds are frozen and slotted. Once a config is loaded nothing downstream can mutate it, which removes a whole class of ranking-drift bugs.

Defaults mirror the reference worked example, so an omitted field still produces a reproducible ranking.

19def load_config(path: str, strict: bool = True) -> Config:
20    """Load and validate a config file from disk."""
21    p = Path(path)
22    if not p.exists():
23        raise ConfigError(f"missing config file: {path}")
24    raw = json.loads(p.read_text(encoding="utf-8"))
25    cfg = _build(raw, strict=strict)
26    _validate(cfg.thresholds)
27    return cfg

The only public entry point. Missing files raise a typed ConfigError instead of leaking FileNotFoundError to the caller.

Reading, building and validating are three separate calls, so each can be unit-tested without touching the filesystem.
