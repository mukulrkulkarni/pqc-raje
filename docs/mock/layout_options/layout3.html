Thresholds are frozen and slotted, so once a config is loaded nothing downstream can mutate it. That removes an entire class of ranking-drift defects.

The defaults mirror the reference worked example, so an omitted field still yields a reproducible ranking.

19def load_config(path: str, strict: bool = True) -> Config:
20    """Load and validate a config file from disk."""
21    p = Path(path)
22    if not p.exists():
23        raise ConfigError(f"missing config: {path}")
24    raw = json.loads(p.read_text(encoding="utf-8"))
25    cfg = _build(raw, strict=strict)
26    _validate(cfg.thresholds)
27    return cfg

The one public entry point. A missing file raises a typed ConfigError rather than letting FileNotFoundError escape to the caller.

Reading, building and validating stay three separate calls so each is unit-testable without touching the filesystem.

35def _validate(t: Thresholds) -> None:

Enforces 0 ≤ q ≤ p ≤ v. Breaking that order silently produces meaningless credibility values, so this guard runs even when strict=False.
