What the module does

1

Criterion record

Data shape

A Criterion holds one decision attribute. The record is frozen. A criterion cannot change after the engine reads it.

Three thresholds give the outranking relation its shape. q is the indifference limit. p is the preference limit. v is the veto limit.

2

Threshold ordering rule

Constraint

The method rejects a criterion that breaks the threshold order. This keeps the concordance index monotone.

0 <= q <= p <= v (and not q = p = v = 0)

Weight normalisation

Formula

The function divides each weight by the sum of all weights. The result is a set of weights that add up to 1.

Entry point and failure mode

I/O

load() reads the records, builds the criteria, and validates each one. The function stops at the first bad record.

The full engine calls load() one time. It then gives the normalised weights to the concordance step.
