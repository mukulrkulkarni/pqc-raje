Documentation

CriterionConfig

Configuration for a single decision criterion in ELECTRE III analysis.

Key Constraint: Thresholds must satisfy 0 ≤ q ≤ p ≤ v

Fields

  • name — Human-readable criterion identifier
  • weight — Relative importance (normalized later)
  • q — Indifference threshold
  • p — Preference threshold
  • v — Veto threshold
  • maximize — If True, higher values are better (default)

Threshold Semantics

The thresholds define preference zones:

  • q (indifference): Differences ≤ q are negligible
  • p (preference): Differences ≥ p show clear preference
  • v (veto): Differences ≥ v override concordance

Example Usage

from electre3.config import CriterionConfig

price = CriterionConfig(
    name="Price",
    weight=0.4,
    q=5,    # $5 difference is negligible
    p=10,   # $10 shows clear preference
    v=20,   # $20 triggers veto
    maximize=False  # Lower price is better
)

Validation

The __post_init__ method validates:

  • q ≥ 0 — No negative indifference
  • p ≥ q — Preference includes indifference zone
  • v ≥ p — Veto includes preference zone
  • weight > 0 — Positive importance
