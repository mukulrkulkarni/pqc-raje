Scientific grounding & calibration notes

Definition: Credibility S(a,b) represents the degree to which "a outranks b" is supported by the evidence, after accounting for both concordance (agreement) and discordance (opposition). This implementation clips output to [0,1] (assuming finite inputs): 0 indicates no support, 1 indicates full support.

Non-compensatory: Unlike purely additive models, a single criterion with high discordance (d_j approaching 1) can substantially reduce credibility, even when other criteria strongly agree. This reflects veto power in ELECTRE III.

Calibration notes:

  • Interpretation: S close to 1 suggests strong outranking; values near 0 suggest weak or no outranking.
  • Diagonal: S(a,a) is often handled upstream; this function does not enforce S(a,a)=0.
  • Threshold sensitivity: Credibility values depend on threshold choices; consider sensitivity analysis.

Sanity checks:

  • Verify S values fall in [0,1]; values outside suggest errors.
  • Spot-check cases where d_j = 1; corresponding S should be 0.
  • NaN/Inf values should be rejected upstream; this module assumes clean data.
