I/O Summary

discordance Input: diff: ndarray(B1,B2,C), p: ndarray(C), v: ndarray(C)
Output: ndarray(B1,B2,C) in [0,1]
Constraint: p ≤ v (validated upstream)
Formula d_j: piecewise linear in [-v, -p] range
Veto: d_j = 1 when diff ≤ -v
None: d_j = 0 when diff ≥ -p
Role in Pipeline Used by: credibility module
Effect: May reduce credibility via veto

Scientific Grounding

Definition Discordance d_j(a,b) measures opposition from criterion j to the assertion "a outranks b." Values typically fall in [0,1]: 0 indicates no opposition, 1 indicates strong opposition (veto).
Assumptions This implementation assumes performance scales are oriented so that higher values indicate better performance (after any maximize/minimize transformation). Thresholds p and v are in the same units as criterion scales.

Threshold Calibration

  • Source: Thresholds (p, v) are typically elicited from domain experts or derived from data variability analysis.
  • Units: p and v should be in the same units as the criterion performance scale.
  • Ordering: Must satisfy p ≤ v; this is validated upstream in config module.
  • Sanity-check: Compare thresholds against observed performance ranges; thresholds larger than the data range may have no effect.

Sanity Checks

  • Range: Verify all d_j values fall in [0,1]; values outside this range suggest implementation or input errors.
  • Spot-check: For a few criterion pairs, manually verify d_j matches expected piecewise formula behavior.
  • Sensitivity: Consider testing how results change with small threshold perturbations.
  • Missing data: This module assumes complete data; NaN/Inf values should be handled upstream.
