Scientific grounding & calibration notes

Definition: The ranking pipeline computes ELECTRE III net flow scores and returns alternatives sorted by descending net flow. Net flow φ = φ+ - φ- where φ+ is outflow (how much a dominates others) and φ- is inflow (how much others dominate a).

Blocking strategy: For large N, storing full N×N credibility matrix is infeasible. Block processing computes B×B submatrices and accumulates flows incrementally. Memory is O(N) for accumulator + O(B²) per block iteration.

Calibration notes:

  • Block size: Larger blocks may be faster but use more memory; tune based on available RAM.
  • Ties: Alternatives with equal net flow may resolve by index order or NumPy implementation details; argsort is deterministic but tie order is not guaranteed.
  • Normalization: Weights are normalized to sum to 1; relative ratios preserved.

Sanity checks:

  • Verify ranking length equals N (number of alternatives).
  • Verify ranking contains each index 0..N-1 exactly once.
  • Spot-check that top-ranked alternatives have highest net flow.
  • NaN/Inf in input matrix should be rejected; validate upstream.
