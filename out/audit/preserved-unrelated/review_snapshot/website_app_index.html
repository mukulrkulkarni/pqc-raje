Phase 1 · guided workflow

Local web application

Use the guided workflow to validate criteria and matrix input before ranking network assets.

Start locally

python scripts/dev_local.py

For the repository default, open http://127.0.0.1:5000/app/.

Complete one task

  1. Select criteria JSON or use the structured form.
  2. Provide a matrix and review its preview.
  3. Confirm the input, then compute the ranking.
  4. Read top alternatives and raw net-flow scores on the results page.

Criteria need positive weights summing to 1, ordered thresholds 0 ≤ q ≤ p ≤ v, and no more than eight criteria. The preview rejects invalid values and mappings. Correct input; do not bypass validation.

Review status: This Phase 1 app guidance is under D3 review. It does not claim release readiness. Known evidence boundary: The app has no JavaScript. Browser reflow, browser zoom, keyboard, offline, and screen-reader evidence remain unverified.
