CLI task

From the repository root, use Python 3.10 or newer and the repository environment.

python -m compileall -q electre3 app
python scripts/convert_matrix_csv.py examples/assets_priority/matrix_with_headers.csv out/assets_priority_cli.npy --has-header --id-col Asset
python -m electre3.cli out/assets_priority_cli.npy examples/assets_priority/criteria.json -y

Approved CSV input has shape (N,C+1): column zero is a source identifier and remaining columns are normalized scores. Direct CSV runs preserve the committed sample identifiers B > A > C. The converter validates then removes source identifiers; its numeric NumPy output uses zero-based positional identifiers. For the committed sample, the converted path prints 1, 0, 2: identifiers, not one-based rank positions. The direct CSV and converted NumPy paths therefore describe the same ordering with different labels. This applies only to committed sample data. The rank uses raw net flow, Φ(a) = Σb S(a,b) − Σb S(b,a), highest first.

Local web task

python scripts/dev_local.py

Open http://127.0.0.1:5000/app/. Provide criteria and a matrix, review the preview, confirm the input, and compute. The app serves HTML without JavaScript.

Use the app page for the launch target and tutorials for detailed guidance.

Input checks

Criteria require a positive weight, ordered thresholds 0 ≤ q ≤ p ≤ v, and maximize. Weights sum to 1; up to eight criteria are accepted. Correct invalid input during preview; do not bypass validation.
